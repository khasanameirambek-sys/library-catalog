# Кітапхана каталогы (Library Catalog)

## Жоба туралы сипаттама
Бұл жоба — «DevOps-тың қолданбалы аспектілері» пәні бойынша СОӨЖ (27-нұсқа) аясында әзірленген шағын бағдарламалық модуль. Қосымша кітапхана каталогын басқаруға, атап айтқанда кітаптарды қосуға, барлық кітаптар тізімін қарауға және атауы бойынша кітаптарды іздеуге арналған.

Жобада GitHub Actions құралы арқылы бағдарламалық кодқа өзгеріс енгізілген сайын (push немесе pull request) unit-тестілерді автоматты түрде іске қосатын базалық CI/CD-конвейері (Build & Test) бапталған.

## Пайдаланылған технологиялар
* **Бағдарламалау тілі:** Python 3.10
* **Тестілеу фреймворкі:** `unittest` / `pytest`
* **Нұсқаларды басқару жүйесі:** Git & GitHub
* **CI/CD құралы:** GitHub Actions

## Жобаның құрылымы
* `app.py` — Кітапхана каталогының негізгі логикасы (класс және әдістер).
* `test_app.py` — Қосымшаның дұрыс жұмыс істеуін тексеретін unit-тесттер.
* `requirements.txt` — Жобаға қажетті тәуелділіктер тізімі.
* `.github/workflows/main.yml` — GitHub Actions CI/CD конфигурация файлы.
